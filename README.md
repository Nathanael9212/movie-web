**🎬 Netfplix**
Website untuk browsing dan mencari informasi film & serial TV dari database TMDB.

**📖 Tentang Aplikasi**
Netfplix adalah platform web yang memungkinkan pengguna menjelajahi ribuan film dan serial TV. Dapatkan informasi lengkap seperti sinopsis, rating, cast, trailer, dan rekomendasi konten serupa.

**✨ Fitur Utama**
**1.Browse Film & TV Show** : Lihat daftar film dan serial populer atau top rated
**2.Filter Genre** : Pilih dari 19+ genre untuk film dan 16+ genre untuk TV
**3.Filter Rating** : Cari konten berkualitas dengan rating 6.0+, 7.0+, atau 8.0+
**4.Pencarian** : Cari film atau TV show dengan keyword
**5.Detail Lengkap** : Lihat info lengkap, trailer YouTube, dan daftar cast
**6.Trending** : Konten paling populer minggu ini

**🎯 Alur Penggunaan**
**1.Homepage** : Lihat featured content dan trending minggu ini
**2.Browse** : Klik "Movies" atau "TV Shows" di navbar
**3.Filter** : Pilih genre dan rating sesuai selera
**4.Detail** : Klik poster untuk melihat informasi lengkap
**5.Trailer** : Tonton trailer langsung di YouTube
**6.Explore** : Lihat rekomendasi konten serupa

**🔑 API Key**
Aplikasi ini menggunakan TMDB API. Dapatkan API key gratis di [themoviedb.org](https://www.themoviedb.org/settings/api)
